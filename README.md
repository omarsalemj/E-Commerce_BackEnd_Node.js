# E-Commerce REST API

A scalable RESTful API for an e-commerce application built with
Node.js, Express.js, MongoDB, and Mongoose.

## Features

- JWT Authentication
- Role-Based Authorization
- Product Management
- Categories & Brands
- Shopping Cart
- Wishlist
- Reviews
- Coupons
- Addresses
- Image Upload
- Filtering
- Sorting
- Searching
- Pagination
- Validation
- Centralized Error Handling

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
